OshiLife update12 revised（2026-09-30）

【今回の重点】
「イベントを登録する」だけでなく、会場で並びながらサクサク使える“当日の操作ハブ”へ再設計。
地上アイドルの部制特典会と、ライブ／フェスの時間管理を同じイベント基盤で扱えるようにする。

■ 下部ナビ
- 並びを「ホーム / 推し / イベント / トーク / 家計簿」に変更。
- イベントを中央に配置。
- トークは登録入口ではなく、過去ログの一覧・検索・振り返り用途として残す。
- ハンバーガーメニューに推し管理、定期入出金、同期状況、Premium、バックアップ、ヘルプ等の管理系導線を追加。

■ 特典会登録フロー
- イベント種類に「特典会」を追加。
- 最初の登録画面は「特典会の種類 / 日付 / 会場（オンライン時はサービス名）」中心に簡素化。
- 特典会ではイベント全体の OPEN / START / END を表示・入力しない。
- 出演者、お目当て、イベントURL、フライヤー、ドリンク等のライブ向け項目も初回登録から外す。
- 保存後、イベント詳細から自分が参加する部・枠だけを追加する2段階方式。
- お話会 / 握手会 / ミーグリ / ハイタッチ / 1ショット / 2ショット / 3ショット / サイン / その他に対応。

■ 参加枠・当日操作
- 参加枠は「部 / メンバー / 内容 / 開始 / 終了 / 受付終了 / 所持枚数 / レーン・チャンネル / メモ」を中心に管理。
- 申込枚数・当選枚数は当日UIから撤去。旧データは読み込み互換を維持。
- 状態は「未参加 / 参加済 / 振替 / 中止」へ簡素化。
- 「＋1枚」「＋5枚」で当日券・追加券をすぐ反映。
- 使用枚数と残数を表示し、「使用＋1」「参加済み」を会場で素早く操作可能。
- イベント詳細上部に「次の予定」を表示。次の2枠まで、時間・部・メンバー・受付終了・所持枚数を確認可能。
- 参加枠からトークログを作成し、撮影系は写真をその枠へ紐付け可能。

■ オフラインファースト
- イベント・参加枠・トーク・写真・支出は端末保存を優先する設計。
- 会場の通信が弱くても、保存済みイベントの確認・参加枠更新・トーク記録等を通信待ちなしで行える方向へ統一。
- 現デモはSharedPreferencesによる端末保存。クラウド同期は後続で「端末保存 → 通信復帰後に同期」を実装予定。

■ 家計簿とイベント支出
- 「支払日」と「イベント開催日」を分離して扱えるように拡張。
- 1件の支払いを複数イベントへ金額配分可能。
  例：9/10 50,000円支払 → 11/3東京20,000円 / 12/10大阪10,000円 / 1/25福岡20,000円。
- 家計簿では支払日に全額を表示し、各イベント詳細ではそのイベントへの配分額のみ表示。
- 配分済額と未配分額を確認可能。
- イベント削除時も支出自体は削除せず、そのイベントへの紐付けだけ解除する。

■ 画像から自動入力
- 精度が低かった単純OCRを自動入力用途から停止。
- プロフィール画像とライブ告知／タイムテーブル画像は、同じ「画像解析エンジン」基盤へ統一。
- UI・保存形式は解析方式に依存させず、クラウドAI → 将来の端末内AI / OCR＋判定へ差し替え可能な構造を追加。
- 現時点ではAPIキーを静的Webアプリへ埋め込まないため、AI解析エンドポイント自体は未接続。接続後は既存の「画像から自動入力」導線をそのまま使用可能。

【互換性】
- update12初版以前の特典会ステータス・申込/当選枚数データは読み込み可能。
- 旧イベント支出のeventIdは新しい配分方式でもそのまま表示可能。
